# Categories

Categories label schedules and transactions and group Plan's **By category** view. Find them in **Plan → Categories**. Tap **Add** to create one, or tap a category to rename it or change its color.

Each category has a name and a color from the built-in palette. The color appears as a dot next to transactions and schedules.

## Deleting

After you confirm, schedules and transactions in a deleted category become **Uncategorized**.
