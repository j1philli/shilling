# History

The History view shows all recorded transactions (postings) with search and time-range filtering.

## Browsing Transactions

Transactions are grouped by date with the most recent at the top. Each row displays the title, account, category (with color indicator), and amount.

Use the time range buttons to filter how far back to look:

- **1M** — last month
- **3M** — last three months
- **6M** — last six months
- **1Y** — last year

The search bar filters transactions by title, account name, or category name. A transaction count is displayed alongside the results.

## Quick Add

The History view includes an inline form for adding one-off transactions that don't belong to a schedule. Fill in the date, title, amount, account, and category, then submit to create an ad-hoc posting directly.

This is useful for unexpected expenses or irregular income that don't warrant creating a schedule.
