# Import

Import adds transactions from a bank's CSV export. Open it with the **Import** button in **Activity**.

1. **Choose CSV file.** Shilling guesses the date, description, and amount columns and the date format from the file.
2. **Check the columns.** Adjust the mapping and the **First row contains column names** switch if needed. Positive amounts import as income and negative amounts as expenses.
3. **Pick the account** to import into, plus a default category.
4. **Review the rows.** Every row is listed. Uncheck rows you don't want, and change the category for individual rows. Rows that match an existing transaction in the account (same date, amount, and description) are marked **Already imported** and unchecked. Rows that can't be read are shown with the reason and skipped.
5. **Import.** Confirm, and the transactions are added to Activity.
