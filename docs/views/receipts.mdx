# Receipts

The Receipts screen provides a standalone store for uploading and managing receipt files.

## Uploading

Add receipts via camera capture, photo picker, or file browser. Each receipt stores:

- **File** — the uploaded image or document
- **Original name** — the source filename
- **Notes** — optional freeform text
- **Receipt date** — when the receipt was issued
- **Amount** — the receipt total

Supported image formats (PNG, JPG, GIF, WebP) display an inline preview. Other file types (HEIC, PDF) can be opened externally.

## Filtering

Filter receipts by attachment status:

- **All** — every uploaded receipt
- **Unattached** — receipts not linked to any posting
- **Attached** — receipts linked to a posting

## Attaching to Postings

Receipts can be attached to existing postings from the receipt screen. A selector shows your 20 most recent postings for quick linking. Once attached, the receipt displays the posting's title and date.

Receipts can also be attached directly from the Weekly view when posting a transaction.

You can detach a receipt from a posting at any time without deleting the receipt itself.
