# Accounts

The Accounts view lets you manage your bank and cash accounts.

## Adding an Account

Enter a name and starting balance to create an account. The balance represents the current amount in the account and is stored directly — it is not derived from transaction history.

## Editing and Deleting

Select an existing account to edit its name or balance. Accounts can be deleted, but note that any schedules or postings referencing the account will retain their original account reference.

## Balance Tracking

Account balances are stored values, not computed from postings. If you want the balance to reflect actual transaction history, you'll need to update it manually. The Weekly view's balance projection uses the stored balance as its starting point and adds/subtracts upcoming occurrences.
